Library Management System 

A simple Library Management System built with Python.

Features Add new books Display all books Search for a book Borrow books Return books Save book data using JSON Load saved books when the program starts Handle invalid number inputs Technologies Used Python Object-Oriented Programming (OOP) JSON pathlib Data Storage 

The system stores book information in a books.json file.

This allows the books and their availability status to remain saved after the program is closed.

How to Run Make sure Python is installed. Download or clone this repository. Run: python library.py Project Structure library-system/ │ ├── library.py ├── books.json ├── README.md └── .gitignore Project Status 

This project is a learning project and will be improved with new features as I continue learning Python.
